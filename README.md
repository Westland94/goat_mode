# GOAT Mode: the static (GitHub Pages) build

This folder is GOAT Mode as a static site.
- **No server:** Python runs in the browser (Pyodide in a Web Worker).
- **Same answers as the Mac build:** checked on all 179 problems (Task 188).
- **The Mac server build in `../app/` is the source.** Everything here that comes from `app/` is generated by `tools/sync_from_app.py`. Edit `app/`, then re-sync; never hand-edit a synced file.

## What ships (the Pages ship list)
**Top-level files:**

| Path | What it is | Origin |
|---|---|---|
| `index.html` | The app page, which loads the shim, then `app.js` | generated by sync from `app/static/index.html` |
| `app.js` | The app | byte copy of `app/static/app.js` |
| `style.css` | Styles | byte copy of `app/static/style.css` |
| `stage.html` | The stage page (kit scenes, plus "watch your run" replays) | generated by sync from `app/static/stage.html`: relative paths, stream via the shim |
| `rive.js`, `rive.wasm` | Rive web runtime 2.55.1 (vendored) | byte copies |
| `mockup-montserrat.ttf` | The stage font (used by `stage.html`) | byte copy |

**Folders:**

| Path | What it is | Origin |
|---|---|---|
| `shim/goat-shim.mjs` | Routes the app's `/api/*` calls to the worker. Owns the 2 s timeout, the progress store and the date pin. | port code |
| `worker/goat-worker.mjs`, `worker/routes.py` | The Web Worker: Pyodide plus the 12 routes | port code |
| `py/` | `engine.py`, `tracer.py`, `stage_emitter.py`, `stage_check.py` | byte copies of `app/*.py` |
| `problems/` | The 179 problem JSONs, plus the generated `index.json` | byte copies |
| `vendor/pyodide/` | Pyodide 314.0.8 (CPython 3.14.2): 5 files, 13,530,536 bytes | from `spike/node_modules/pyodide` |
| `stage/kit-{001,003,010,132}.riv` | The prebuilt stage scenes | byte copies of `../stage/kit-*/build/*.riv` |

**Totals:** 203 files, 20,064,123 bytes. `tools/ship_list.py` prints the list with md5s and greps it for publish blockers.

**Does not ship (dev only):** `probe/` (headless test drivers), `spike/` + `spike183v/` (the Pyodide parity spike, `node_modules`) and `tools/` (sync, ship list, scratch server).

**No `.nojekyll` needed:** no shipped path starts with `_` (checked by `tools/ship_list.py`), so Jekyll would publish every file as-is.

## Run it locally

```
python3 web/tools/sync_from_app.py      # refresh web/ from app/ (prints an md5 manifest)
python3 web/tools/serve.py 8780         # static server for web/ (serves .mjs and .wasm with the right types)
```

Then open `http://127.0.0.1:8780/`. The first load takes ~5 s while Pyodide boots. Every call after that is fast.

## Where progress lives
- **Progress (items, attempts, intros seen) lives in the browser's `localStorage`** under `goat-progress`. It's per browser and per site origin, and it isn't synced anywhere.
- **Clearing site data wipes it.** A different browser or device starts fresh.
- **There's no two-tab guard yet** (the last save wins).
- **To pin "today" for testing:** add `?today=YYYY-MM-DD` to the URL, or set `localStorage["goat-today"]`.
